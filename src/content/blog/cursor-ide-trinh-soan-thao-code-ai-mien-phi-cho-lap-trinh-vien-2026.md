## 2. 4 Tính Năng "Thần Thánh" Trên Cursor Bản Miễn Phí

### 1. Phím tắt `Cmd + K` (hoặc `Ctrl + K`): Chỉnh sửa code ngay tại chỗ
Bạn chỉ cần bôi đen một đoạn hàm (function), nhấn `Cmd + K` và gõ yêu cầu bằng tiếng Việt: *"Thêm try-catch để bắt lỗi và viết comment giải thích từng dòng"*. AI của Cursor sẽ sinh mã trực tiếp và hiển thị dạng Diff (xanh lá cây là code mới, đỏ là code cũ) để bạn quyết định Accept hay Reject.

### 2. Phím tắt `Cmd + L` (hoặc `Ctrl + L`): Trợ lý Chat ngữ cảnh sâu
Khác với ChatGPT web, cửa sổ Chat của Cursor hiểu chính xác bạn đang mở file nào. Bạn có thể gõ `@filename` để đính kèm ngữ cảnh của một file cụ thể, hoặc gõ `@web` để AI tự tìm kiếm tài liệu hướng dẫn mới nhất trên Internet hoàn toàn **miễn phí**.

### 3. Tự động hoàn thiện code đa dòng (Cursor Tab)
Khi bạn đang viết một đoạn logic, Cursor không chỉ gợi ý 1 từ mà dự đoán trước cả khối logic 3-5 dòng tiếp theo với màu xám mờ. Bạn chỉ cần nhấn phím **`Tab`**, toàn bộ đoạn code chuẩn xác sẽ được chèn vào ngay lập tức.

### 4. Tự sửa lỗi Terminal chỉ bằng 1 nút bấm (Fix in Terminal)
Khi chạy lệnh build hoặc khởi động server bị báo lỗi đỏ trong Terminal, Cursor sẽ hiển thị một nút bấm **"Fix with AI"**. Khi bấm vào, AI sẽ phân tích log lỗi của terminal, đọc lại file code bị sai và đề xuất cách sửa ngay lập tức mà bạn không cần phải copy lỗi lên Google hay StackOverflow.

## 3. Mẹo Dùng Cursor Free Không Lo Hết Lượt Truy Vấn AI

Khi sử dụng gói Hobby miễn phí, để không bị gián đoạn công việc khi hết lượt Fast requests, bạn có thể áp dụng 2 mẹo sau:
1. **Sử dụng API Key cá nhân (Bring Your Own Key):** Cursor cho phép bạn nhập OpenAI API Key, Anthropic API Key hoặc Google Gemini API Key của chính bạn vào phần cài đặt (`Cursor Settings` → `Models`). Việc dùng API theo nhu cầu thực tế (Pay-as-you-go) sẽ rẻ hơn rất nhiều so với đăng ký gói 20$/tháng.
2. **Tắt AI khi chỉ gõ text cơ bản:** Khi bạn chỉ đang sửa nội dung tĩnh hoặc làm các thao tác lặp lại đơn giản, bạn có thể tạm tắt tính năng gợi ý AI để tiết kiệm hạn ngạch cho những thuật toán hóc búa cần suy luận cao.

## 5. Câu Hỏi Thường Gặp (FAQ)

### Dùng Cursor IDE bản Free có an toàn và bảo mật mã nguồn không?
**Có.** Cursor có tùy chọn **Privacy Mode** (Chế độ riêng tư). Khi bật tính năng này trong phần Settings, Cursor cam kết không lưu trữ code của bạn trên máy chủ và không sử dụng code của bạn để huấn luyện mô hình AI.

### Tôi có thể chuyển toàn bộ extension từ VS Code sang Cursor được không?
**Hoàn toàn được.** Khi cài đặt Cursor lần đầu tiên, phần mềm sẽ hiển thị tùy chọn **"Import from VS Code"**. Chỉ với 1 click, toàn bộ extension, phím tắt (keybindings) và theme giao diện quen thuộc của bạn sẽ được sao chép nguyên vẹn sang Cursor trong vài giây.

### Khi hết lượt truy vấn nhanh (Fast requests), Cursor Free có dùng tiếp được không?
Có. Khi dùng hết hạn ngạch truy vấn tốc độ cao hàng tháng, bạn vẫn có thể sử dụng tiếp tính năng AI Chat và Composer với tốc độ tiêu chuẩn (Slow queue) mà không bị khóa tài khoản hoặc bắt buộc phải trả phí.
