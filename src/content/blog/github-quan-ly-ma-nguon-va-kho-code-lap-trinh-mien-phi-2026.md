| :--- | :---: | :---: | :--- |
| **Chi phí hàng tháng** | **0 VNĐ (Free trọn đời)** | ~4 USD / user / tháng | Bản Free đáp ứng 100% nhu cầu cá nhân & nhóm sinh viên. |
| **Kho mã nguồn riêng tư (Private Repos)** | **Không giới hạn (Unlimited)** | Không giới hạn | Bạn có thể giấu mã nguồn đồ án môn học thoải mái không tốn phí. |
| **Số cộng tác viên trong Repo riêng tư** | **Không giới hạn cộng tác viên** | Không giới hạn | Thỏa sức làm bài tập nhóm 5-10 bạn cùng lúc. |

## 2. 4 Tính Năng "Đắt Giá" Nhất Trên Bản GitHub Free

### 1. Tạo không giới hạn Private Repository
Trước đây, GitHub bắt người dùng phải trả tiền mới được tạo kho code riêng tư (Private). Nhưng hiện nay, bạn có thể tạo **hàng nghìn kho code riêng tư hoàn toàn miễn phí**. Chỉ những người bạn cấp quyền mới được đọc code, giúp bảo mật tuyệt đối các bài thi, đồ án tránh bị copy bài.

### 2. Tự động hóa kiểm thử CI/CD với GitHub Actions (2.000 phút free)
Mỗi khi bạn đẩy code mới lên GitHub (`git push`), GitHub Actions có thể tự động:
- Chạy toàn bộ các bài unit test để kiểm tra lỗi cú pháp.
- Tự động đóng gói phần mềm và đẩy lên máy chủ Vercel hoặc Cloud hoàn toàn tự động.
- Đối với các kho code mã nguồn mở (Public), số phút chạy Actions là **miễn phí không giới hạn**!

### 3. Lập trình mọi lúc mọi nơi với GitHub Codespaces (120 giờ free)
Bạn đang dùng máy tính bảng hoặc laptop cấu hình yếu không cài được môi trường Node.js hay Python phức tạp? Chỉ cần nhấn phím **`.` (dấu chấm)** trên bàn phím khi đang mở repo GitHub trên trình duyệt, một giao diện VS Code nền web sẽ mở ra ngay lập tức với đầy đủ máy chủ đám mây để bạn code và chạy terminal mượt mà.

### 4. Hosting web miễn phí với GitHub Pages
Chỉ cần đẩy mã nguồn trang web HTML/CSS/JS lên một repo Public và bật tính năng GitHub Pages trong Settings, trang web của bạn sẽ được xuất bản lên Internet với đường link `username.github.io/project` hoàn toàn **miễn phí**, có sẵn chứng chỉ bảo mật HTTPS.

## 3. Quy Tắc "Vàng" Khi Dùng GitHub Miễn Phí Tránh Lỗi Tràn Bộ Nhớ

1. **Không đẩy thư mục `node_modules` hoặc file ảo `venv`:** Hãy luôn tạo file `.gitignore` để loại bỏ các thư mục thư viện nặng hàng gigabyte.
2. **Tuân thủ giới hạn file 100MB:** GitHub giới hạn mỗi file đơn lẻ không được vượt quá 100MB. Nếu cần lưu file mô hình AI hoặc video nặng, hãy sử dụng Git LFS hoặc lưu trên Google Drive/Hugging Face.
3. **Tuyệt đối không đẩy mật khẩu và API Key:** Không bao giờ commit các file chứa chuỗi kết nối cơ sở dữ liệu hoặc khóa API lên GitHub Public để tránh bị hacker đánh cắp tài nguyên đám mây.
