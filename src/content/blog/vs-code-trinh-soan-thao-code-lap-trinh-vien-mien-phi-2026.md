## 2. 5 Tính Năng Tuyệt Vời Khiến VS Code Luôn Là Lựa Chọn Số 1

### 1. Kho Extension khổng lồ giải quyết mọi nhu cầu
Dù bạn học môn nào trong trường đại học, VS Code đều có extension **miễn phí** hỗ trợ:
- **Prettier / ESLint:** Tự động căn chỉnh thụt dòng và làm đẹp code chuẩn phong cách ngành.
- **Live Server:** Mở trang web HTML/CSS/JS lên trình duyệt và tự reload tức thì khi lưu file.
- **Python Extension (Microsoft):** Tự động phát hiện môi trường ảo virtualenv, gợi ý cú pháp và hỗ trợ Jupyter Notebook trực tiếp.
- **GitLens:** Hiển thị rõ ràng ai là người viết dòng code này và commit vào thời gian nào.

### 2. Bộ gỡ lỗi Debugging trực quan
Bạn không cần phải dùng lệnh `print()` hay `console.log()` thủ công khắp nơi để tìm lỗi. VS Code cho phép bạn click chuột để đặt **Breakpoint (Điểm dừng)**, theo dõi giá trị của từng biến (Variable Watch) và chạy từng bước câu lệnh (Step Over, Step Into) một cách khoa học.

### 3. Tích hợp Terminal đa luồng
Ngay bên trong cửa sổ VS Code, bạn có thể mở cùng lúc nhiều tab Terminal (PowerShell, Bash, zsh, WSL), chạy song song cả server Backend, client Frontend và câu lệnh Git mà không cần mở nhiều cửa sổ rời rạc.

### 4. Đồng bộ hóa cài đặt qua đám mây (Settings Sync)
Khi bạn đổi máy tính mới hoặc dùng máy tính tại phòng thực hành của trường, chỉ cần đăng nhập tài khoản GitHub vào VS Code, toàn bộ cài đặt giao diện, phông chữ, phím tắt và extension của bạn sẽ được tải về tự động **miễn phí 100%**.

### 5. Lập trình từ xa qua SSH & Docker (Remote Development)
Với extension Remote - SSH miễn phí, bạn có thể biến chiếc laptop cá nhân mỏng nhẹ thành màn hình điều khiển máy chủ server GPU khổng lồ đặt trên trường hoặc cloud, viết code mượt mà như đang lưu trữ trực tiếp trên máy mình.

## 3. Mẹo Thiết Lập VS Code Cho Người Mới Bắt Đầu Để Code Nhanh Gấp Đôi

Để có trải nghiệm lập trình tốt nhất trên VS Code hoàn toàn miễn phí, hãy bật ngay 3 tùy chọn sau:
1. **Bật Auto Save:** Vào `File` → Tích chọn `Auto Save`. Code của bạn sẽ được lưu tự động sau mỗi lần gõ, tránh rủi ro mất bài khi máy tính sập nguồn bất ngờ.
2. **Bật Format On Save:** Vào `Settings` (phím tắt `Cmd + ,` hoặc `Ctrl + ,`) → Gõ tìm kiếm `Editor: Format On Save` → Tích chọn. Giờ đây, mỗi khi lưu file, code sẽ tự động căn lề thụt dòng chuẩn xác.
3. **Mở thanh lệnh Command Palette (`Cmd + Shift + P` / `Ctrl + Shift + P`):** Đây là phím tắt quyền lực nhất của VS Code, cho phép bạn gọi mọi chức năng, đổi theme, cài extension mà không cần chạm tay vào chuột.

## 5. Câu Hỏi Thường Gặp (FAQ)

### Dùng VS Code miễn phí cho công ty và dự án kiếm tiền có bị vi phạm bản quyền không?
**Hoàn toàn không.** Giấy phép bản quyền của Microsoft Visual Studio Code cho phép cá nhân, sinh viên, giáo viên và mọi doanh nghiệp thương mại sử dụng tự do mà không phải trả bất kỳ khoản phí nào.

### VS Code khác gì so với Visual Studio bản đầy đủ (Visual Studio Community/Professional)?
VS Code là trình soạn thảo mã nguồn gọn nhẹ (Code Editor), tập trung vào tốc độ và sự linh hoạt thông qua các extension. Trong khi đó, Visual Studio đầy đủ (như bản 2022) là một môi trường phát triển tích hợp khổng lồ (IDE) nặng hàng chục gigabyte, chuyên sâu cho hệ sinh thái .NET và C++ của Windows. Đối với học sinh, sinh viên và lập trình viên hiện đại, VS Code là lựa chọn gọn gàng và phổ biến hơn rất nhiều.
